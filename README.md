# FAST Mobile Order

Trabalhei na empresa insertsoft. Essa empresa desenvolve sistemas para automação comercial. A empresa não possui a versão mobile, para que os restaurantes que utilizam o sistema da insertsoft, possam retirar pedidos na mesa, utilizando um tablet ou celular. Estou com a ideia de desenvolver, para a insertsoft, uma versão mobile do sistema insertsoft FAST.  Estou na dúvida de como fazer esse sistema mobile. Acredito que um sistema web, que rode em navegadores, e que possam ser abertos pelo tablet, seja mais produtivo do que um sistema mobile android e IOS, o que você acha?
